# Lavendar Theme for VS Code

A modern, minimal dark theme designed to provide a sleek coding environment with high-contrast pastel accents. Built with a comfortable dark gray workspace base, deep purple accents, and bright lavender highlights, this theme maximizes code readability while minimizing eye strain during long development sessions.

## 🎨 Color Palette

*   **Workspace Base:** Neutral Dark Gray (`#1E1E22`)
*   **Primary Accent:** Lavender (`#C299CE`)
*   **Secondary Accent:** Deep Purple (`#3A194D`)
*   **Text & Details:** Soft White (`#FDF9FA`) and Muted Gray (`#87848D`)

## ✨ Features

*   **Optimized Syntax Highlighting:** Functions, keywords, and constants utilize bright lavender tokens for clear visual hierarchy.
*   **Polished UI Components:** Features a deep purple active tab border, matching file explorer sections, and customized minimap slider states.
*   **Integrated Terminal:** Fully styled terminal window background that seamlessly matches the dark gray workspace aesthetics.
*   **High Contrast Search:** Enhanced Find and Replace highlights utilizing deep purple opacity for quick text scanning.

## 🚀 Local Installation

To use this theme locally on your machine without publishing it to the extension marketplace, follow these steps:

1. Download or clone this repository.
2. Move the entire `lavendar-theme` folder into your local VS Code extensions directory:
    *   **Windows:** `C:\Users\<YourUsername>\.vscode\extensions`
    *   **macOS / Linux:** `~/.vscode/extensions`
3. Restart Visual Studio Code.
4. Open the Color Theme picker using `Ctrl + K` then `Ctrl + T` (or `Cmd + K` then `Cmd + T` on Mac).
5. Select **Lavendar Theme** from the list.
